# 🎵 Core Player - Шпаргалка

## Быстрый запуск
```bash
./start.sh
```
Или вручную:
- Backend: `cd backend && source venv/bin/activate && uvicorn app.main:app --reload`
- Frontend: `cd frontend && npm run dev`
- Браузер: http://localhost:3000

---

## ⚙️ Настройки

### Фон
**Настройки → Фон приложения**
- **Динамический**: авто-смена под обложку трека
- **Кастомный**: укажите `/background.jpg` или свой путь

### Кодек
**Настройки → Аудио кодек**
- MP3 / RAW / Opus / FLAC

---

## 🎵 Воспроизведение

### Начать играть
1. Кликните на трек → автоматически откроется полноэкранный режим
2. Кликните на альбом → список треков → выберите трек

### Полноэкранный режим (Now Playing)
- Большая обложка слева
- Тексты песен справа
- Кнопки управления под обложкой
- **Клик по строке текста** → перемотка

### Элементы управления
- **Play/Pause**: большая белая кнопка
- **Previous/Next**: кнопки по бокам
- **Shuffle**: перемешать очередь (синяя = вкл)
- **Repeat**: 
  - Серая = выключен
  - Синяя ↻ = повтор всех
  - Синяя ↻1 = повтор трека
- **Favorite** (♥): добавить в избранное (красная = добавлен)

## 🎨 Интерфейс

### Sidebar
- **Стрелка** в заголовке → скрыть/показать
- **Гамбургер** (при скрытом) → открыть
- Состояние сохраняется

### PlayerBar (нижняя панель)
```
[Обложка + Название + ♥]  [◀ ▶ ▷]  [↻]
```
- Автоматически сдвигается при скрытии sidebar
- Элементы по центру экрана

### Страницы
- **Главная**: недавние альбомы + случайные треки
- **Избранное**: starred альбомы
- **Треки**: случайные 100 треков
- **Артисты**: 
  - Список с алфавитным фильтром
  - **Клик на артиста** → альбомы артиста
- **Альбомы**: 
  - Сетка альбомов
  - **Клик на альбом** → треклист
- **Плейлисты**: все плейлисты из Navidrome

## 🎤 Тексты песен (Lyrics)

### Синхронизация
- Автоматическая подсветка текущей строки (белая + увеличена)
- Автоматический скролл

### Перемотка
- **Клик по любой строке** → перемотка на это место

## 💡 Советы

### Кастомный фон
1. Поместите изображение в `frontend/public/`
2. Настройки → Пользовательский фон → `/имя_файла.jpg`

### Горячие клавиши (скоро)
- Space - Play/Pause
- ← → - Previous/Next
- R - Toggle Repeat
- S - Toggle Shuffle

### Проблемы?
1. Проверьте что Navidrome запущен: http://localhost:4533
2. Проверьте логи backend
3. Откройте DevTools (F12) → Console для ошибок JS
