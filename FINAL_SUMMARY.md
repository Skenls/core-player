## 🎯 Как использовать новые функции

### 1. Настройки фона
1. Откройте Настройки (иконка шестеренки в sidebar)
2. Выберите "Динамический фон" или "Пользовательский фон"
3. Для кастомного: укажите путь (например `/background.jpg`)
4. Нажмите "Закрыть"

### 2. Скрыть sidebar
1. Кликните стрелку (ChevronLeft) в заголовке sidebar
2. Sidebar плавно уезжает влево
3. Появляется кнопка-гамбургер для раскрытия
4. PlayerBar автоматически растягивается на всю ширину

### 3. Воспроизведение с Now Playing
1. Кликните на любую карточку трека
2. Трек начнет играть
3. Автоматически откроется полноэкранный режим
4. Увидите большую обложку + тексты песен

### 4. Работа с текстами
1. Текущая строка подсвечена белым + увеличена
2. Автоматический скролл к текущей строке
3. Кликните по любой строке → перемотка на это место

### 5. Добавить в избранное
- **В PlayerBar**: кнопка сердечка рядом с названием трека
- **В Now Playing**: кнопка сердечка справа от кнопок управления
- Клик → красная заливка

### 6. Управление повтором
- **PlayerBar**: кнопка Repeat справа
- **Now Playing**: кнопка Repeat в ряду управления
- Клик: off → all (синий Repeat) → one (синий Repeat1) → off

### 7. Просмотр артиста
1. Откройте вкладку "Артисты"
2. Кликните на артиста
3. Увидите все альбомы этого артиста
4. Кнопка "Назад к артистам" для возврата

### 8. Просмотр альбома
1. Откройте вкладку "Альбомы"
2. Кликните на альбом
3. Увидите треклист
4. Кнопка "Воспроизвести" → весь альбом с начала
5. Клик на трек → начать с этого трека

### 9. Выбор кодека
1. Откройте Настройки
2. Выберите нужный кодек:
   - **MP3**: универсальный
   - **RAW**: без сжатия
   - **Opus**: высокое качество
   - **FLAC**: lossless
3. Нажмите "Закрыть"

## 🎨 Дизайн-решения

### Цветовая палитра
```css
/* Фон */
background: dynamic | custom

/* Glassmorphism */
backdrop-blur-2xl
bg-black/40
border-white/10

/* Акценты */
blue-400 (repeat active)
red-500 (favorite active)
white/50 (inactive)
```

### Анимации
```typescript
// Sidebar
transition: { type: 'spring', stiffness: 400, damping: 30 }

// PlayerBar
transition: 'left 300ms'

// NowPlaying
transition: { duration: 0.8 } // blur background

// Lyrics
transition: { duration: 0.3, ease: 'easeOut' }
```

### Компоновка
```
┌─────────────────────────────────────────────────────┐
│ [Sidebar]  [Main Content]                          │
│ (toggle)   (auto-adjust margin)                    │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ [Track Info + ♥] [▶Controls] [Repeat]              │
│   ← Left           Center →    Right →             │
└─────────────────────────────────────────────────────┘
```

## 📝 Известные ограничения

### 1. Избранное (UI only)
- Кнопка работает только в UI
- Не синхронизируется с Navidrome
- Нужно добавить API: `/api/library/star`, `/api/library/unstar`

### 2. Кодек (не применяется)
- Настройка сохраняется, но не используется
- Нужно передавать в stream URL: `?format={codec}`
- Backend должен поддерживать транскодирование

### 3. Кастомный фон (только локальные файлы)
- Работают только файлы из `/public`
- Внешние URL требуют CORS
- Можно добавить drag & drop загрузку
