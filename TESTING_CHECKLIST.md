# ✅ Чеклист тестирования Core Player

## Перед началом
- [ ] Backend запущен на http://localhost:8000
- [ ] Frontend запущен на http://localhost:3000
- [ ] Navidrome запущен на http://localhost:4533
- [ ] Вошли в систему с учетными данными Navidrome

---

## 1. Настройки фона

### Динамический фон (по умолчанию)
- [ ] Откройте Настройки (иконка шестеренки)
- [ ] Проверьте что выбран "Динамический фон"
- [ ] Включите трек
- [ ] Фон должен показывать размытую обложку трека
- [ ] При смене трека фон должен плавно меняться

### Кастомный фон
- [ ] Откройте Настройки
- [ ] Выберите "Пользовательский фон"
- [ ] Введите `/background.jpg`
- [ ] Нажмите кнопку загрузки
- [ ] Фон должен смениться на кастомное изображение
- [ ] Закройте и снова откройте настройки
- [ ] Проверьте что настройка сохранилась

---

## 2. Скрытие sidebar

### Скрыть
- [ ] Кликните на стрелку (ChevronLeft) в заголовке sidebar
- [ ] Sidebar должен плавно уехать влево
- [ ] Должна появиться кнопка-гамбургер (Menu) слева вверху
- [ ] PlayerBar должен растянуться на всю ширину
- [ ] Контент должен сдвинуться влево (margin-left: 0)

### Показать
- [ ] Кликните на кнопку-гамбургер
- [ ] Sidebar должен плавно выехать справа
- [ ] Кнопка-гамбургер должна исчезнуть
- [ ] PlayerBar должен сузиться
- [ ] Контент должен сдвинуться вправо (margin-left: 256px)

### Persistence
- [ ] Скройте sidebar
- [ ] Обновите страницу (F5)
- [ ] Sidebar должен остаться скрытым

---

## 3. Адаптивная нижняя панель (PlayerBar)

### Компоновка
- [ ] Включите трек
- [ ] Проверьте что обложка и название слева
- [ ] Проверьте что кнопка избранного (♥) рядом с названием
- [ ] Проверьте что элементы управления строго по центру экрана
- [ ] Проверьте что кнопка Repeat справа

### Адаптация к sidebar
- [ ] Откройте sidebar → PlayerBar должен сдвинуться вправо
- [ ] Закройте sidebar → PlayerBar должен растянуться влево
- [ ] Переход должен быть плавным (300ms)

### Кнопки
- [ ] Кликните Play/Pause → должно работать
- [ ] Кликните Previous → предыдущий трек
- [ ] Кликните Next → следующий трек
- [ ] Кликните Repeat → должен переключаться (off → all → one)
- [ ] Кликните ♥ (избранное) → должна появиться красная заливка

---

## 4. Полноэкранный режим (Now Playing)

### Открытие
- [ ] Кликните на карточку трека
- [ ] Трек должен начать играть
- [ ] Автоматически должен открыться Now Playing
- [ ] Фон должен показывать обложку или кастомное изображение

### Интерфейс
- [ ] Проверьте большую обложку слева (480px)
- [ ] Проверьте название и артиста под обложкой
- [ ] Проверьте кнопки управления:
  - [ ] Shuffle
  - [ ] Previous
  - [ ] Play/Pause (большая белая кнопка)
  - [ ] Next
  - [ ] Repeat
  - [ ] Favorite (♥)

### Закрытие
- [ ] Кликните стрелку назад (ArrowLeft) вверху слева
- [ ] Now Playing должен закрыться
- [ ] Трек должен продолжать играть в PlayerBar

---

## 5. Синхронизация текстов песен

### Если у трека есть LRC
- [ ] Откройте Now Playing для трека с текстами
- [ ] Проверьте что тексты отображаются справа
- [ ] Проверьте что текущая строка подсвечена белым и увеличена
- [ ] Проверьте что происходит автоскролл к текущей строке

### Перемотка
- [ ] Кликните по любой строке текста
- [ ] Трек должен перемотаться на время этой строки
- [ ] Подсветка должна переместиться на выбранную строку

---

## 6. Кнопки избранного

### В PlayerBar
- [ ] Включите трек
- [ ] Кликните на ♥ рядом с названием
- [ ] Иконка должна залиться красным
- [ ] Повторный клик → иконка должна стать прозрачной

### В Now Playing
- [ ] Откройте Now Playing
- [ ] Кликните на ♥ справа от кнопок управления
- [ ] Иконка должна залиться красным
- [ ] Проверьте синхронизацию с PlayerBar

---

## 7. Управление повтором (Repeat)

### Режимы
- [ ] Кликните Repeat в PlayerBar
- [ ] Серая иконка → off (не повторять)
- [ ] Еще клик → синяя иконка ↻ → all (повтор всех)
- [ ] Еще клик → синяя иконка ↻1 → one (повтор трека)
- [ ] Еще клик → серая иконка → off

### Проверка работы
- [ ] Установите "Повтор трека" (↻1)
- [ ] Дождитесь окончания трека
- [ ] Трек должен начаться сначала

---

## 8. Детальные страницы артистов

### Главная страница
- [ ] Откройте вкладку "Артисты"
- [ ] Проверьте отображение сетки артистов
- [ ] Проверьте алфавитный фильтр вверху
- [ ] Кликните на букву → должны отфильтроваться артисты

### Детальная страница
- [ ] Кликните на любого артиста
- [ ] Должна открыться страница с альбомами артиста
- [ ] Проверьте большой аватар артиста вверху
- [ ] Проверьте количество альбомов
- [ ] Кликните "Назад к артистам" → должен вернуться на главную

---

## 9. Детальные страницы альбомов

### Главная страница
- [ ] Откройте вкладку "Альбомы"
- [ ] Проверьте отображение сетки альбомов
- [ ] Кликните на альбом

### Детальная страница
- [ ] Должна открыться страница с треклистом
- [ ] Проверьте большую обложку (264px)
- [ ] Проверьте информацию: название, артист, год, количество треков
- [ ] Проверьте кнопку "Воспроизвести"

### Воспроизведение
- [ ] Кликните "Воспроизвести" → весь альбом с начала + Now Playing
- [ ] Вернитесь на страницу альбома
- [ ] Кликните на любой трек → начать с этого трека + Now Playing
- [ ] Кликните "Назад к альбомам" → вернуться на главную

## 🐛 Известные ограничения

1. **Избранное**: только UI, не сохраняется в Navidrome
2. **Кодек**: настройка сохраняется, но не применяется к stream
3. **Кастомный фон**: только локальные файлы из `/public`
