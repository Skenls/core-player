# 🎵 Core Player - Полное руководство

## ✨ Новые функции

### 1. Настройки фона
- **Динамический фон**: автоматически меняется под обложку текущего трека
- **Пользовательский фон**: загрузите своё изображение
  - Поместите изображение в `frontend/public/` (например, `background.jpg`)
  - В настройках укажите путь: `/background.jpg`

### 2. Скрытие бокового меню
- Кнопка со стрелкой в заголовке sidebar
- Плавная анимация появления/скрытия
- Кнопка-гамбургер при скрытом меню

### 3. Адаптивная нижняя панель
- Элементы управления по центру
- Автоматически сдвигается при открытом/закрытом sidebar
- Кнопка избранного слева
- Кнопка повтора справа

### 4. Полноэкранный режим при клике на трек
- Клик на карточку трека → воспроизведение + открытие Now Playing
- Большая обложка альбома слева
- Тексты песен справа с синхронизацией
- Клик по строке текста → перемотка на это место

### 5. Управление избранным
- Кнопка сердечка в PlayerBar (нижняя панель)
- Кнопка сердечка в NowPlayingView (полноэкранный режим)
- Красная заливка при добавлении в избранное

### 6. Режимы повтора
- **Выключен** (серая иконка)
- **Повтор всех** (синяя иконка Repeat)
- **Повтор трека** (синяя иконка Repeat1)
- Переключение по кругу

### 7. Детальные страницы
- **Артисты**: клик → альбомы артиста
- **Альбомы**: клик → треклист с возможностью воспроизведения

### 8. Выбор кодека
В настройках доступны:
- **MP3** (универсальный, хорошее сжатие)
- **RAW** (без сжатия, оригинал)
- **Opus** (высокое качество, малый размер)
- **FLAC** (lossless, максимальное качество)

## 🎯 Как использовать

### Настройка фона

1. **Динамический** (по умолчанию):
   - Фон автоматически меняется под обложку трека
   - Размытие + анимация "дыхания"

2. **Пользовательский**:
   ```bash
   # Поместите изображение в public
   cp ~/Downloads/my-background.jpg frontend/public/background.jpg
   ```
   
   Затем в настройках:
   - Выберите "Пользовательский фон"
   - Введите `/background.jpg`
   - Нажмите кнопку загрузки

### Работа с треками

1. **Воспроизведение с полноэкранным режимом**:
   - Кликните на карточку трека
   - Автоматически откроется Now Playing
   - Увидите большую обложку + тексты песен

2. **Управление в полноэкранном режиме**:
   - Shuffle (перемешать)
   - Previous/Play/Next/Repeat
   - Favorite (добавить в избранное)
   - Клик по тексту → перемотка

3. **Синхронизация текстов**:
   - Текущая строка выделена белым + увеличена
   - Автоматический скролл к текущей строке
   - Клик по любой строке → перемотка на это место

### Навигация

1. **Sidebar**:
   - Клик на стрелку → свернуть/развернуть
   - При свернутом: кнопка-гамбургер для раскрытия

2. **Артисты**:
   - Фильтр по алфавиту
   - Клик на артиста → альбомы артиста
   - Кнопка "Назад к артистам"

3. **Альбомы**:
   - Клик на альбом → треклист
   - Большая кнопка "Воспроизвести" → весь альбом
   - Клик на трек → начать с этого трека

## 🎨 Кастомизация

### Цветовая схема
Все настройки в `frontend/src/store/uiStore.ts`:
```typescript
backgroundMode: 'dynamic' | 'custom'
customBackgroundUrl: '/background.jpg'
audioCodec: 'mp3' | 'raw' | 'opus' | 'flac'
```

### Изменение фона по умолчанию
Отредактируйте:
```typescript
customBackgroundUrl: '/helpers/background.jpg'  // ваш путь
```

## 🔧 Технические детали

### Структура состояния UI
```typescript
interface UIState {
  // Navigation
  isSidebarOpen: boolean;
  activeTab: 'home' | 'favorites' | ...;
  
  // Modals
  isNowPlayingOpen: boolean;
  isSettingsOpen: boolean;
  
  // Settings (persistent)
  backgroundMode: 'dynamic' | 'custom';
  customBackgroundUrl: string;
  audioCodec: 'mp3' | 'raw' | 'opus' | 'flac';
}
```

### Анимации
- Sidebar: `x: -280` → `x: 0` (spring physics)
- PlayerBar: `left: 256px` → `left: 0` (transition 300ms)
- NowPlaying: полноэкранное появление с blur background

### Persistence
Настройки сохраняются в localStorage:
- `core-ui-settings`: фон, кодек, sidebar state

## 📝 Горячие клавиши (планируется)

- `Space` - Play/Pause
- `→` - Next track
- `←` - Previous track
- `R` - Toggle repeat
- `S` - Toggle shuffle
- `L` - Toggle lyrics
- `F` - Fullscreen

## 🐛 Известные ограничения

1. **Избранное**: 
   - Пока только UI, не синхронизируется с Navidrome
   - Нужно добавить API endpoints для star/unstar

2. **Кодек**:
   - Настройка пока только сохраняется
   - Нужно передавать в stream URL: `/api/stream/{id}?format={codec}`

3. **Кастомный фон**:
   - Поддерживаются только локальные файлы в `/public`
   - Для URL нужна CORS поддержка
